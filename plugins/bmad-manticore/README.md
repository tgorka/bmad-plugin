# BMad Manticore

AI video production pipeline: brain dump → script in your own words →
word-level cut plan → preview render → brand-themed motion graphics →
title/thumbnail package → offered final render, with hard approval gates
at every taste decision.

Upstream: [bmad-code-org/bmad-manticore](https://github.com/bmad-code-org/bmad-manticore)
· pinned to **v4.0.0** · 15 skills.

## Install

```
/plugin marketplace add tgorka/bmad-plugin
/plugin install bmad-manticore@bmad-method
```

## Prerequisites

Manticore is a BMad *module*, not a standalone plugin. Its skills resolve
their configuration through the core BMad runtime:

```
uv run {project-root}/_bmad/scripts/resolve_config.py --key modules.manticore
```

So a working repo needs, in this order:

1. The **`bmad`** plugin installed and `/bmad:init` run — that
   materialises `_bmad/scripts/` and `_bmad/custom/`.
2. `uv` (Python ≥3.11), `ffmpeg`, `node`/`npx`, `git`.
3. `mc-setup` run once. It interviews you, builds the brand folder,
   installs the HyperFrames motion-graphics skills, and writes
   `[modules.manticore]` into `_bmad/custom/config.toml`. Until it has,
   every other `mc-*` skill stops and routes you back to it.

Start with:

> talk to Manny

Optional lanes (local TTS, music, SFX, model downloads of several GB)
are opt-in and are configured during `mc-setup`. Setting `[editor] name`
to `resolve` turns on the DaVinci Resolve lane, which needs DaVinci
Resolve Studio (`mc-setup` checks for it); every other editor keeps the
fcpxml lane and needs nothing extra.

## Known upstream defect at v4.0.0

- **`mc-agent` is not registered in `_bmad/config.toml`'s agent roster.**
  The roster is written by the core install, which does not know about a
  sibling plugin. The skill itself works; only the `bmad-help` agent list
  omits Manny.

The v1.0.1 defect that kept `mc-audio` from installing (invalid YAML in
its frontmatter) is fixed at v4.0.0, so all 15 declared skills install.
v4.0.0 is upstream's first tag since v1.0.1 and includes the 3.0.0 and
3.1.0 work that had sat on `main` marked Unreleased; along the way
`mc-ograf` was removed (OGraf folded into `mc-graphics`, where `ograf`
stays an alias for the `hyperframes` engine) and the per-skill
`customize.toml` files were dropped.

## Provenance

Generated by `bun run sync`: the repo is cloned at the pinned tag and
handed to `npx bmad-method install --custom-source <local path>`; the
`mc-*` skill directories the installer emits are copied here 1:1. Never
hand-edit `skills/` or `runtime/` — both are wiped on every sync.
